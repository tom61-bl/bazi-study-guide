# 阴阳五行学习指南 · Bazi Study Guide

> 八字入门筑基的交互式学习站：阴阳五行 · 十天干 · 十二地支
> 一屏读懂干支关系，网页直接刷卡复习。

## 在线访问

**[https://tom61-bl.github.io/bazi-study-guide/](https://tom61-bl.github.io/bazi-study-guide/)**

## 功能

一个自包含的单文件 Web 应用（无后端、无构建、双击即开），三大模块：

### 壹 · 基础笔记
阴阳五行 · 十天干 · 十二地支的系统化整理：

- 五行德性（木主仁 / 火主礼 / 土主信 / 金主义 / 水主智）与行为气质
- 月令旺相休囚死判定、生克耗泄助、反生反克口诀
- 十干意象（甲木如雷如树，乙木如风如花草……）、天干五合、天干四冲
- 十二支字义意象、三会局、三合局、六合、六冲、相刑、六害、六破、暗合四绝
- 年干 / 年支推算方法、地支藏干表

### 贰 · 互动图解
四个可视化罗盘，全部可点：

- **五行生克盘**：东木南火西金北水中土，点击任意五行高亮 生 / 泄 / 克 / 耗 / 助
- **天干关系盘**：阳干实心、阴干空心，切换五合 / 四冲图层
- **地支关系盘**：八类关系（三会 / 三合 / 六合 / 六冲 / 相刑 / 六害 / 六破 / 暗合）自由叠加
- **干支纪年计算器**：输入任意公历年份，自动推算干支并双盘定位

### 叁 · 卡片复习
内置 **147 张记忆卡片**，网页版间隔重复（类 Anki）：

- 不认识（1）本轮重现、认识（2）、简单（3）自动拉长复习间隔
- 进度保存在浏览器 localStorage，下次继续
- 键盘操作：空格翻卡，1 / 2 / 3 评分

## 本地运行

无需任何构建，直接用浏览器打开 `index.html` 即可。

```bash
git clone https://github.com/tom61-bl/bazi-study-guide.git
cd bazi-study-guide
# 双击 index.html，或：
python -m http.server 8000
```

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无构建工具）
- SVG 渲染互动罗盘
- localStorage 驱动的简化 SM-2 间隔重复算法
- 字体：Noto Serif SC / Noto Sans SC
